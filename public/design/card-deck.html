The card deck

Every information card the apps are built from — WaterWayz underway, the marina desk, the InteliMaris monitoring loop, and the account surfaces behind both. Each one is rendered live from packages/design tokens on this page, so the class recipe under it drops into apps/web unchanged.

What every card on this page obeys

Severity is never colour alone

The icon and the words distinguish it too. A card that only turns red fails WCAG 1.4.1 and fails a helm at dusk.

Unknown renders as unknown

An em dash, never a zero and never a computed guess. Clearance keeps its datum discipline.

A bare number is not a measurement

Metric where the world is metric, nautical where the sea is nautical. Every value carries its unit; digits are tabular.

Map colour is API data

Hazard, depth, AIS and POI hues are served taxonomy (§4 / ARC-04). Every one on this page is injected from a mock response, never a class.
